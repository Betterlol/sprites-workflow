# 网页工作台（用户指南）

面向通过网页创作和检查 Sprite 的用户。安装与启动见 [项目首页](../../README.md)，数据和 CLI 见 [共享参考](../README.md)。当前工具不自动生成原画，也不会自动判断角色一致性或动作自然度。

## 工程与布局

从工程列表新建工程，设置名称、目录名、画布与锚点。名称和目录支持中文；目录名留空时使用工程名称。打开后，顶部 **My Projects / 工程名** 中的 My Projects 可返回工程列表，图标导航用于角色基准、切割、调整、动作与导出。

左侧固定的“工作目录”贯穿各页，包含 **参考图、原图素材、动作列表、衔接序列、单帧资源**。展开文件夹选择资源，使用相应的添加入口导入或新建。角色基准放在右侧工作区，不占左侧独立栏。切换页面保留当前草稿，目录各文件夹保留折叠状态。

右侧是当前画布、时间轴和属性。桌面可拖动分隔条调整宽度和时间轴高度；布局尺寸只保存在浏览器。窄屏使用素材、画布与时间轴、属性切换。工程设置、重新载入与版本记录位于工程选项中。

## 1. 参考图与原图

在参考图目录导入人设、风格与正式 Idle 基准；参考图不参与切割。在原图素材目录导入已采用的动作 spritesheet 或单帧修复原图；支持批量导入，某张失败不撤销已成功导入的图片，版本冲突时会停止并提示。

参考图支持 GIF 动图：每个 GIF 保留为一个原始文件，在角色基准页按文件自带的时长与循环设置播放，不拆分为多张图片，也不生成动作帧。

角色基准页用于并排对照所选参考与当前 idle 的播放首帧。播放首帧不等于已批准的正式基准；需要协作时在工程 README 中记录精确参考与版本。

已有 processed 单帧仍可兼容导入，但新制作或修复的原画建议保留 source 来源。独立导入或无法对应原图的单帧可以参与编排，处理控件会显示只读。

## 2. 切割与独立保存

1. 在工作目录选择原图，切换到切割页。选择自动连通域、规则网格、整张单帧或手动区域。
2. 使用“选择 / 移动”调整已有区域，拖动边角手柄缩放；使用“新建区域”拖出框。右侧可输入 X、Y、宽、高。方向键移动 1 px，Shift 加速到 10 px，Esc 取消当前拖动。
3. 人工编辑会转为矩形区域；自动连通域的像素掩膜不继续用于该手动矩形。自动重新识别后应复核每个区域。
4. 点击“保存当前切割”，只提交当前原图切割、稳定帧 ID 和原尺寸切片，其他动作、缩放等草稿继续保留为未保存状态。

移动、缩放、排序不会重编号素材；新增区域分配新 ID。删除仍被已保存或草稿动作、序列引用的区域受到保护。带已保存单帧覆盖的区域也应先重置并保存，再移除。

原尺寸切片是可重建缓存。调整预览会复用有效切片；只改缩放和偏移不要求重跑切割。缓存无效时预览在内存重新切割，不暗中写盘；再次保存切割可重建缓存。保存切割不会删除已有 processed 图片。

## 3. 单帧与整组调整

在调整页选择预览动作，按该动作实际的**游戏顺序和逐帧时长**检查；重复引用和跨原图帧都会保留。没有动作时使用明确标记的素材检查。平时调整页只显示游戏播放，展示播放在导出设置中配置。

时间轴选择帧可定位其原图；修改单帧缩放或偏移只更新该帧的处理预览，同一素材在动作中的所有重复位置共用修改结果。更新预览会保留播放位置；首次预览、缓存淘汰、整组规则或原图变化时，需要重新计算受影响帧。

可在处理结果画布拖动单帧修改偏移，也可输入数值；一次拖动对应一次撤销，Esc 取消。单帧缩放是绝对覆盖，留空继承整组倍率。整组目标高度依据该原图最高完整轮廓计算共享倍率，不会把每帧都拉成同高。道具、特效可能改变轮廓，身体大小和脚底位置仍需人工对照。

使用地面线、前帧叠图和 Idle 参考检查。Idle 叠图取 idle 动作按游戏规则展开后的第一帧，不自动绑定 references 中的正式基准。

确认后点击“应用调整并保存工程”：只替换当前原图中像素变化的 PNG，同时保存整个草稿。其他动作和序列会使用新的正式图片；单纯参数预览不会替换正式素材。

## 4. 动作与衔接序列

从工作目录选择或新建动作、衔接序列。两者使用相同的资源槽位，可混合加入**单帧、动作、序列**。目录中的动作或序列可拖入时间轴，也可用加入按钮添加；单帧支持多选加入。

每张时间轴卡片是一次引用。拖动排序，复制或移除；属性中修改重复、速度、引用范围，或单帧停留时间。范围从 0 开始，结束步包含在内，使用的是被引用资源展开后的步编号。设置只影响当前这次引用，不修改原资源。

“展开帧”查看最终帧、全局步编号、时长及来源，点击帧可定位播放。“编辑原资源”进入被引用资源，再通过“返回父组合”返回。编辑原资源会影响所有引用它的组合；移除槽位不会删除原资源或 PNG。

动作用于游戏交付，序列用于组合与衔接检查；序列也能加入动作参与导出。共享边界不会自动去重，需要用范围或编排明确决定。子资源的无限循环不会让引用无限展开，循环次数由槽位有限重复决定。

编辑器按游戏播放检查。高级引用设置中的游戏 / 展示模式是**这一处子资源引用的选择**，与全局编辑器预览模式不同；默认规则、继承时长与兼容说明见 [资源组合参考](../reference/resources.md)。

播放 / 暂停用 Space，左右方向键单步；Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做。观察用的倍速与循环不改写正式播放时长。实际自然度需要在正常速度、慢放与逐帧检查，尤其检查完整动作的真实离开、返回和衔接位置。

## 5. 保存、应用与冲突

| 操作 | 保存配置 | 正式图片与其他文件 |
| --- | --- | --- |
| 预览、时间轴编辑 | 仅浏览器草稿 | 不变 |
| 保存工程 / Ctrl+S | 当前完整草稿 | 不重算 processed |
| 保存当前切割 | 当前原图 extract 与帧身份 | 更新对应原始切片缓存，processed 不变 |
| 应用调整并保存工程 | 当前完整草稿 | 仅更新当前原图像素变化的 PNG |
| 准备缺失素材 | 当前完整草稿 | 只补充缺失原图处理目录，不重建已有目录 |
| 导入、删除、显式兼容迁移 | 当前完整草稿 | 修改对应文件，注意同时提交其他草稿 |
| 导出 | 不保存工程 | 读取草稿编排和已应用图片，临时生成下载文件 |

“草稿待保存”表示配置尚在浏览器；“预览待应用”表示处理预览尚未写入正式图片；“素材待更新”表示原图或规则与正式图片不一致。保存参数不代表处理完成。工程画布或锚点变化后，应逐张重新应用；兼容导入的手工帧不会自动变更画布。

配置和素材均有版本保护。其他窗口或 CLI 修改文件时，旧页面不能直接覆盖。有草稿可下载配置草稿或合并配置，冲突字段需选择后再保存；数组不会按位置悄悄拼接。只有图片变化时可刷新素材保留配置草稿。切换或关闭工程前留意未保存提示。

## 6. 导出与展示设置

顶部导出入口可下载动作资源、当前序列播放产物或完整工程。按需选择帧 PNG、图集与 TexturePacker JSON、WebP/GIF 等。完整工程备份范围见 [工程目录](../reference/project-layout.md)。

**展示播放的顺序、FPS、逐步时长、统一停留与循环在导出设置中调整**。可恢复游戏播放。展示参数应用后进入当前草稿，保存工程才持久化；生成导出会先校验并应用当前设置。它不修改日常编辑器的游戏预览方式，也不能代替游戏动作验收。

游戏资源保存展开后的实际帧顺序和逐帧时长。接入引擎时应使用时长元数据，不能只读取根动作默认 FPS 而忽略片段节奏。

## 删除、恢复与旧素材

工作目录里的参考图、原图、动作、衔接序列，以及单帧卡片旁都有 **删除** 按钮；单帧和组合也可使用多选删除。删除按钮始终针对它旁边的资源，不需要先打开该资源。

删除前会弹出确认。资源仍被使用时，会列出受影响的动作和序列，确认后执行 **强制删除**：移除对应引用，按剩余帧调整片段范围与展示顺序；没有剩余帧或无法兼容不同播放方式的片段引用也会移除，空组合保留供继续编辑。取消确认不会修改草稿或文件。

删除动作和序列只修改草稿，可撤销，保存工程后生效，素材图片会保留。删除参考图、原图或单帧会保存整个工程草稿，并写入版本记录，不能用普通网页撤销恢复文件。删除原图会清理对应切片、处理帧与规则；删除自动生成的单帧不改变切割规则，后续应用可能重新生成。

“版本记录”可恢复受影响文件的上次状态，恢复前检查外部修改。历史不包含在普通工程 ZIP 中。操作前可以先导出完整备份。

“保留已有最终帧”是旧项目兼容迁移，会重新建立动作引用，应在开始新的编排前明确决定是否使用。现有 imports、_approved 和旧 reference 继续兼容；工作台不自动迁移 assets，也不自动为旧平铺动作建立子动作引用关系。
