# 如何让 Agent 跑流水线

这份说明给使用者看。告诉 Agent 工程、目标、采用的参考或原画，以及希望它完成到哪一步；工程已有约定直接沿用，无需自己写生图提示词或把所有工具参数抄一遍。

## 可以这样布置任务

已有原画：

> 工程是 workspaces/<工程ID>，原画在 <图片路径>。请导入并切割，调整到与现有 Idle 的身体尺度和接地点一致，组成 <动作名>，输出 review 材料。网页由我测试。

制作长动作：

> 在 <工程ID> 制作 <动作描述>，沿用现有参考。请按需要拆成子动作，以实际首尾帧约束衔接，再组装完整动作并检查。复杂的中间段可以采用中间关键姿态拆分法；最终交给我验收。

只做局部修改：

> <工程ID> 的 <动作名 / 具体帧或接缝> 有 <问题>。请只调整这一处，保留其他素材与编排，说明影响范围和待检查项。

这些是给 Agent 的任务描述，不是发给图像模型的提示词模板。你可以自由描述目标，不要求固定措辞。

## 交接时看什么

确认采用的来源、修改范围和动作编排；查看 Agent 实际检查了什么、哪些还待你验收。保存工程只保存配置，处理参数需要应用后才更新正式图片。Agent 与网页共享文件，操作期间避免双方同时修改同一配置。

正常速度看节奏，慢放或逐帧看人物、接地点与接缝。报告通过或动画成功导出不能代替这些判断；也不必为每一步要求截图或长篇报告。

网页操作见 [工作台指南](workbench.md)，可选生成方法见 [制作技巧](../reference/animation-techniques.md)。
