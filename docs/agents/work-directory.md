# Agent 工作目录（按需查阅）

- `_work/<task>/`：候选、临时脚本与必要比较材料，确有需要再建，不要求固定子目录或截图数量。
- `source/`：采纳的原画，通过 projects.py 导入；processed 由切割和处理生成。
- `references/`：用户参考、已确认 Idle 基准和必要正式记录，不放迭代候选。
- 工程 README：本次来源、编排取舍与检查结果，简要补充即可。

完整工程 ZIP 不含 _work、exports 和历史目录，正式结论不要只留在其中。清理已有文件前检查引用和所有者。

review 优先用通用 qa、check-composition、check-export，参数见 [工程操作](../reference/project-operations.md)。必要时可在本任务目录做额外比较，不要求逐帧网页截图；工具报告不替代视觉判断。
