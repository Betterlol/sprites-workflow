# 动画制作技巧（按需参考）

供人和 Agent 选择制作方法，不是每次任务的必做清单。基本来源与验收要求见 [制作流程](../agents/artwork-workflow.md)。这里只记录方法与适用条件，不规定生图提示词。

## 中间关键姿态拆分法（二分法）

适合长动作中某一段变化复杂，或两个既有端点 A、B 很难一次生成自然过渡时。先确定一个有意义的中间姿态 M，再分别生成 A → M、M → B 两段 spritesheet。

1. 明确 A、B 的真实播放帧及运动方向，选择能拆开难点的 M，例如接触道具、转身完成或落地。M 不必位于时间正中间，两段时长也不必相同。
2. 可以单独生成 M：实际提供 A、B、Idle 和必要邻帧，确认其角色尺度、姿态、接触与道具状态能承接两端。候选留在 _work，选定后固定图片版本。
3. 分别以 A / M、M / B 为首尾参考生成完整 sheet，同时提供 Idle 与必要运动上下文。两段必须使用同一版本 M。
4. 采纳的原画导入 source 后处理。M 若参与播放，也先作为原图导入并处理；最终组装复用同一份 M，保留原 A、B，默认不重复播放 M。生成 sheet 中近似重画的端点不自动替换已采用端点。
5. 检查 A → M、M → B 两段及完整 A → M → B，重点检查 M 两侧的方向、速度和状态，避免在中点突然停住或反向。有意停顿明确设置时长。

若 M 本身难以成立，重新选择姿态或调整拆分；若某一段仍过复杂，可继续分段，但不要细分成逐张独立生帧。关键姿态是生成约束，不能仅凭它们匹配就宣布整段连贯。
