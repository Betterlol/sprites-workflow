# Sprite Workbench 制作与操作

把动画任务落实为可追溯的素材、明确的运行时编排和实际查看过的成果。此 skill 随本仓库使用，通过 [Agent 入口](../../../AGENTS.md)按任务读取；命令从仓库根目录执行。

## 选择本次需要的指导

| 当前任务 | 阅读内容 |
| --- | --- |
| 新建、扩展、修原画或处理复杂过渡 | [制作技巧](references/production.md)：参考输入、分段、端点与中间关键姿态 |
| 导入、切割、单帧偏移或保存编排 | [工程操作](references/operations.md)：状态、草稿、版本与写入范围 |
| 拼接、验收或导出 | 工程操作中的编排核对与交付部分，结合[视觉检查](../../normal/visual-review.md) |

只读与当前任务相关的部分。通用工作方法见[工作指导](../../normal/README.md)，字段与范围的权威说明见[配置参考](../../../docs/configuration.md)，完整参数见[命令参考](../../../docs/commands.md)及对应命令的 `--help`。

## 开始时确定四件事

1. **目标与现状。** 阅读目标工程 README、当前配置与 `status`，区分已经应用的图片、参数草稿、人工修图和候选。沿用用户已有授权，不重复请求逐步确认。
2. **采用的视觉输入。** 实际查看角色基准、问题帧及邻帧。调用图像工具时实际传入相关图片；无法接收图片时说明限制，不把文字描述当作已经约束了端点。
3. **影响范围。** 区分原图区域 ID、PNG 引用、资源槽位和展开播放位置。确认修改是针对共享图片、整个子动作，还是某一次播放；只改一个位置时建立独立变体或局部编排。
4. **检查对象。** 游戏结果以最终 `runtime` 展开为准，展示结果按其 `display` 设置另查。将准备检查的范围与真实前后动作、采用版本对应起来。

## 操作与返工的判断

| 问题 | 处理与验证 |
| --- | --- |
| 画错肢体、服饰或道具 | 修原画；提供基准、坏帧与两侧邻帧，保留采用来源 |
| 切错、尺度或接触点偏移 | 检查原图与区域，再改切割或处理规则；避免用缩放掩盖结构错误 |
| 缺少一段运动、跨批次衔接困难 | 按语义拆段或选择中间关键姿态，再检查两侧过渡与完整动作 |
| 停顿、漏帧、倒跳 | 对照展开顺序、重复与毫秒时长；有意停留写进编排 |
| 单段正常、完整动作异常 | 核对真实运行时边界与完整组成，再检查实际前后动作 |

每次修改解决一个可定位的问题。编排改变时比较完整动作与独立的预期组成；共享素材或子资源改变时复查受影响的引用。程序核对通过后仍需实际查看，不能用降低 FPS、跳过异常帧或淡化接缝替代修复。

## 结束与交接

只补充足够继续工作的记录：采用基准与原画来源、变体或替换的对应关系、边界与时序取舍、检查版本，以及通过或待确认项。已有记录直接引用，不建立固定报告包。

基准、图片、处理或编排改变后，旧的相关验收结论需要重新建立。交付简述成果位置、主要变化、实际检查范围与剩余限制；没有看过连续播放时，明确待视觉验收。
