# 工作方法

## 先形成可执行的判断

结合用户要求与现有素材，确定这次要解决的动作意图、视觉约束和交付范围。例如“补齐转身过渡”与“让站立循环更平稳”需要不同的处理，不能仅按缺少多少帧来决定工作量。

从相关参考中提取影响本次工作的约束：角色比例与辨识特征、视角、画风、道具、运动方向、画面尺度和接触位置。优先延续用户指定的基准；参考之间存在冲突时，先判断冲突是否影响本次目标，必要时询问。不要自行把一张新生成图片提升为整套素材的新标准。

## 按任务推进

### 新建动画

先用关键姿态表达动作，再补足过渡和节奏。预备、发力、接触、缓冲与恢复可作为分析线索，具体保留哪些环节由动作决定，不套用固定帧数或固定阶段。

选择能暴露主要风险的少量帧试作，例如静止基准、最大幅度姿态和接触姿态。把它们放在一起比较，并按预期顺序和时长播放，确认角色一致、动作可读、处理方式可行后，再展开其余帧。已有方向足够明确时自行继续，无需新增逐步审批。

### 扩展已有动画

先播放待扩展片段及相邻动作，理解已有的运动轨迹、节奏和循环方式。新帧同时参考角色基准与相邻帧，保证进入和离开扩展片段都能衔接。

优先复用适合的姿态和素材；新增过渡应解决明确的运动缺口。复制帧、延长停留和增加过渡帧的作用不同，根据节奏选择，不以帧数增加作为完成标准。

### 修复局部问题

先定位问题出现在哪一层，再选择最小有效修改：

| 观察到的问题 | 优先检查 |
| --- | --- |
| 五官、服饰、道具或肢体形状突变 | 原画与相邻姿态是否一致 |
| 身体残缺、碎片混入或特效消失 | 原图内容、切割范围与区域归属 |
| 整体跳动、大小闪变或脚底滑动 | 原始姿态、缩放、锚点、偏移与接触关系 |
| 动作停顿、倒跳或重复感异常 | 帧顺序、重复、逐帧时长与播放方式 |
| 单段正常、拼接后突兀 | 片段边界的姿态、位置、速度和停留 |
| 预览正常、交付结果异常 | 是否检查了相同版本、编排和输出设置 |

这些是排查入口，不是唯一归因。先比较问题帧与相邻帧，再验证判断；不要仅凭一张缩略图就重做整段。

## 制作与处理中的取舍

**生成与修图。** 选择能保持既有角色和画风的方法，向所用工具提供相关视觉参考。每批结果先查看再选用；反复出现同类偏差时，调整参考、约束或方法，不靠不断增加候选数量掩盖问题。已有局部成果可用时，尽量保留可用部分。

**切割与透明背景。** 保留角色、道具和属于该帧的特效，检查细线、半透明边缘与相邻姿态是否被误切。去除背景时区分背景颜色与角色内部同色区域，避免连带删除眼白、高光或服饰细节。不同姿态的切片边界可以不同，不必强求相同外接框。

**尺寸与对齐。** 用共同基准判断角色尺度，避免按每帧外接框分别缩放而产生体积闪变。对齐依据动作中的接触与运动关系：站立可参考脚底，腾空应保留轨迹，挤压、伸展、透视和有意位移不应被机械拉平。特效扩张也不应导致身体被整体缩小。

**编排与节奏。** 先检查关键姿态能否表达动作，再调整过渡和时长。保留必要的停留、加速和缓冲，不用统一时长代替节奏设计。循环只在需要循环时处理接缝；一次性动作应关注起止姿态及其与相邻动作的连接。

## 迭代与结束

每次围绕一个明确问题修改，并比较修改前后是否改善、是否引入新问题。局部改动先查受影响帧和边界；涉及全局尺度、风格或播放规则时，扩大检查范围。

使用[视觉检查](visual-review.md)评估将要交付的成果。达到本次目标即可结束；剩余限制如实说明。交付时简要指出可查看的成果、主要变化、实际检查范围和待确认项，不额外生成与任务无关的过程材料。
