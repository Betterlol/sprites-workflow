# 视觉检查

检查围绕用户目标和本次改动展开。以已确定的角色基准与动作意图为参照，结合单帧比较和连续播放；检查工具与材料按需选择，不要求每项任务都制作完整检查包。

## 单帧与角色一致性

| 检查点 | 判断方式 |
| --- | --- |
| 轮廓与结构 | 关键姿态是否清楚，肢体、五官、服饰与道具是否出现不合理的增减、连接或变形 |
| 角色一致性 | 比较基准和相邻帧的比例、配色、视角、线条与材质；区分动作变形与角色设计漂移 |
| 透明与裁切 | 在浅、深或棋盘背景上查看白边、黑边、背景残留、杂点、半透明损失和被截断的内容 |
| 尺度与位置 | 在同一画布尺度下比较，判断身体大小、重心与接触点是否合理；不要让预览自动适应掩盖大小变化 |
| 可读性 | 在实际使用尺寸下确认动作和重要细节能被辨认，放大查看只用于定位问题 |

并排图适合发现整体差异，叠图适合定位偏移，放大图适合检查边缘；它们都不能单独证明动画流畅。

## 连续播放与衔接

先按实际顺序和目标时长播放，再用慢放或逐帧查看定位异常。慢放流畅不代表正常速度下可读，单帧好看也不代表运动连贯。

| 检查点 | 需要辨别的现象 |
| --- | --- |
| 动作意图 | 发力方向、接触、恢复是否看得懂；关键姿态是否被过快略过或无故停留 |
| 运动连续性 | 位置、轮廓、体积、遮挡与道具轨迹是否发生无意跳变，细节是否闪烁 |
| 接触关系 | 应固定的接触点是否滑动，离地与落地是否可信；有意滑步、腾空和位移按动作要求判断 |
| 节奏 | 停留、重复、加减速是否服务于动作，是否因漏帧、重复帧或时长设置产生卡顿 |
| 循环接缝 | 连续播放数轮，检查尾帧到首帧的位置、姿态、运动趋势与停留；首尾图相同也可能造成顿挫 |
| 片段连接 | 将修改片段与实际前后动作一起播放，检查边界；不只播放修改片段本身 |

一次性动作不必强行闭环。明确的夸张、顿帧和拖影应按目标风格判断，不自动当作错误抹平。

## 检查真正交付的版本

确认查看的内容与交付成果使用相同的素材版本、帧顺序和时长。涉及导出时，查看实际导出结果，检查透明、尺寸、顺序、节奏以及编码造成的变化，不能只凭编辑预览判断成品。

当工程存在人工修图、外部修改或未保存草稿时，核对最终采用的内容，避免把旧文件、临时预览或另一种播放设置当成此次结果。

## 如何形成结论

把发现转化为可定位的问题，例如“循环末尾回到首帧时头部向右跳动”，并说明受影响的帧或边界。避免只写“有点怪”“不够自然”，也不在没有确认原因时直接指定重做整段。

程序与文件检查说明数据或输出是否符合约定；视觉结论应来自实际查看。只能查看静态帧时，不声称连续播放已通过。受环境或用户指定检查方式限制而未验证的部分，作为待确认项说明。

交付说明保持简短：成果位置、完成了什么、检查了什么，以及仍影响使用的问题或待确认项。除用户要求或排查需要外，不额外建立截图清单、验收报告或逐帧记录。
